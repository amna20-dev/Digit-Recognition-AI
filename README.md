# Digit Recognition AI

## About the Project
Digit Recognition AI is an Android application that recognizes handwritten digits from 0 to 9 using a trained Machine Learning model.

Users can draw a digit on the screen, and the application predicts which number has been drawn.

## Features
- Draw digits using your finger.
- Recognize handwritten numbers from 0 to 9.
- Display prediction results.
- Show prediction confidence.
- Clear the drawing and try again.
- Works with a TensorFlow Lite model.

## Technologies Used
- Java
- XML
- Android Studio
- TensorFlow Lite
- Machine Learning
- MNIST Dataset

## Machine Learning Model
The model is trained using the MNIST handwritten digit dataset.

- Input: 28 × 28 grayscale image
- Output: 10 classes (0–9)
- Model format: TensorFlow Lite (`.tflite`)

## How to Use
1. Open the application.
2. Draw a digit from 0 to 9.
3. Press the Predict button.
4. View the predicted digit and confidence.
5. Press Clear to draw another digit.
